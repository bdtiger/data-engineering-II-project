\section{Related Work}

Predicting software repository popularity using metadata features such as activity, age, and contributor diversity is a well-studied problem. Distributed machine learning research highlights the need to distribute ML workloads across multiple machines when computation or data size grows [4]. This motivates our use of Celery and RabbitMQ to distribute prediction tasks across workers. Our work applies a neural network regressor to GitHub star prediction and deploys the best model in a production environment.

On the infrastructure side, we adopt VM contextualization via Ansible to automate environment setup across Dev and Prod VMs~\cite{armstrong2015}. We follow a Git Hook-based CI/CD pipeline for continuous model delivery~\cite{qian2020orchestrating}. Our Docker and RabbitMQ-based horizontal scaling design follows scalable batch processing approaches for scientific workloads using container orchestration~\cite{hariri2018}.
