\section{Related Work}

The prediction of repository popularity on GitHub has attracted growing research interest,
particularly as social coding platforms have become central to software development practice.

Borges et al.~\cite{borges2016} conducted one of the first systematic analyses of the factors
that drive GitHub repository popularity. Their study found that external social links---especially
references from platforms such as Hacker News and Reddit---are among the strongest predictors of
rapid star growth, alongside intrinsic factors such as project age and the number of contributors.
Their work motivates the inclusion of activity-based features such as fork count, watcher count,
and subscriber count in our feature set.

Hudson et al.~\cite{hudson2022} applied machine learning techniques to predict the long-term
trajectory of open-source project success, framing popularity prediction as a regression problem
over historical activity signals. Their findings support the use of ensemble methods such as
Random Forest and Gradient Boosting, which capture non-linear interactions between features more
effectively than linear baselines.

Tian et al.~\cite{tian2015} examined the relationship between software quality metrics and
community adoption, showing that issue response time and commit frequency are meaningful signals
for predicting user engagement. This reinforces the relevance of features such as open issue
count and days since the last push that we extract from the GitHub API.

Taken together, these works establish the feasibility of feature-based star prediction and
motivate the comparative evaluation of multiple regression models under a consistent evaluation
protocol.
