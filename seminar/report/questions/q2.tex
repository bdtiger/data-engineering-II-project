\section{Q2: How does contemporary serverless architecture relate to the digitalization of 
society and Big Data applications?}


Contemporary serverless architecture has become an important part of the digitalization of society because it allows organizations to create and run scalable digital services without having to manage physical servers or complicated infrastructure themselves \cite{baldini2017}. In serverless computing, cloud providers automatically handle resources and run functions only when they are needed. This approach supports modern services such as online banking, e-commerce, IoT systems, streaming platforms, and AI applications, where user activity can change quickly. Since companies only pay for the resources they actually use, serverless computing can reduce costs and make innovation easier and more accessible \cite{baldini2017,jonas2019}.

Serverless architecture is also strongly connected to Big Data applications. Today’s Big Data systems generate huge amounts of real-time information from mobile devices, sensors, social media, and online transactions \cite{chen2014}. Serverless platforms can automatically scale up or down to process this data efficiently. Technologies such as AWS Lambda, Google Cloud Functions, and Azure Functions are often combined with Big Data tools like Apache Kafka, Spark, and cloud storage systems to support real-time analytics and event-driven data processing \cite{baldini2017,jonas2019}. Because of this, serverless solutions are especially useful for recommendation systems, fraud detection, and smart city technologies.

Another major benefit is faster software development and deployment. Developers can spend more time focusing on the application itself instead of maintaining servers, which improves flexibility and supports continuous updates \cite{jonas2019}. At the same time, serverless systems also have some disadvantages, such as startup delays, dependence on specific cloud providers, and difficulties when debugging distributed systems \cite{baldini2017}. Even with these challenges, serverless computing is increasingly seen as an important technology for supporting both the digital transformation of society and the growing need for scalable Big Data processing.
